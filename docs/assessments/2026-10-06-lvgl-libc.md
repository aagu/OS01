# OS01 libc 对 LVGL 的适配评估

基线：OS01 `62f9cac76ff7734d4444cf04b748dfc003554452`；LVGL v9.5.0
（`85aa60d18b3d5e5588d7b247abf90198f07c8a63`）。

结论：当前 libc 已能满足 LVGL 基础软件 GUI 的编译和符号依赖；无需先建设完整 POSIX libc。建议先使用 `LV_USE_OS=LV_OS_NONE`、单个 UI 线程、软件渲染、内建字体和编译进程序的图片。

## 实际检查

使用 LVGL 原始 lv_conf_template.h，启用配置内容；关闭的可选功能保持模板默认值。使用 Clang 的 x86_64 裸机目标、OS01 libc 头、freestanding 编译、栈保护，不使用宿主 libc 头或库。

| 配置 | 结果 |
|---|---|
| 内建 allocator/string/sprintf | 463 个 C 翻译单元全部编译成功 |
| 三项切换为 LV_STDLIB_CLIB | 463 个 C 翻译单元全部编译成功 |
| 上述两项分别与 OS01 libc.a 做 ld.lld -r 链接 | 无未解析符号 |
| LV_USE_FLOAT=1 + LV_USE_MATRIX=1 | lv_matrix.c 编译失败：缺 cosf、sinf、tanf、roundf |
| LV_USE_OS=LV_OS_PTHREAD | lv_pthread.c 编译失败：缺 semaphore.h；源码另需线程创建/join、属性、递归 mutex、条件变量等 |
| LV_USE_FS_POSIX=1，盘符 A | 文件驱动编译失败：unistd.h 未声明 lseek，stdio.h 缺 SEEK_* |
| LV_USE_FS_STDIO=1，盘符 A | 文件驱动编译失败：缺 SEEK_*、fseek、ftell |

基础 CLIB 配置需要的外部符号：malloc/free/realloc、memcpy/memmove/memset/memcmp、strlen/strnlen、strcpy/strncpy/strcmp/strncmp/strcat/strncat/strchr、vsnprintf，以及编译器栈保护符号。当前 libc.a 全部提供。

运行 `make test-host` 退出码 0；构建 profile 的 libc staging 退出码 0。

## 缺口与建议

- 文件后端：lseek 和 SEEK_* 当前位于 libc/include/sys/stat.h，属于声明位置不兼容，不是没有 lseek 实现。可把公开声明整理到标准头；stdio 路线还需补 fseek/ftell 的真实实现。
- 线程后端：当前 pthread 仅有普通 mutex，且 pthread_mutex_init 忽略属性。不能假装提供递归 mutex 来接入 LVGL。初期单 UI 线程无需该后端。
- 数学：基础配置不依赖完整 libm；开启浮点矩阵或更多矢量功能后需补数学实现并重新审计依赖。圆角、阴影和普通控件不要求先补完整 libm。
- 内存：CLIB allocator 接口齐全，但现有 malloc 为简单 first-fit，realloc 分配后复制，calloc 缺乘法溢出检查。未测试 LVGL 长时间运行中的碎片和分配失败行为。可先用内建 TLSF，并按实际场景配置内存池；大型绘制缓冲用 mmap。
- 计时：OS01 已有 clock_gettime 与 poll，可在用户态适配 LVGL tick 和 timer loop。

## 验证边界

这是编译与符号检查，不是完整 ELF 启动、显示接入或 QEMU 运行验证。可选配置只编译对应入口文件，错误列表不代表其全部依赖。未验证 FreeType、ThorVG、PNG 等第三方库。
