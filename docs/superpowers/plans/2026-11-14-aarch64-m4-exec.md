# AArch64 M4.13：原生 `SYS_exec` 与用户栈参数传递实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在双架构共享系统调用层实现原生 `SYS_exec`（11）与 `deep_copy_argv` 参数深拷贝，新增跨架构 `syscall_strnlen_user(addr, max)` 原语，并在 AArch64 实现基于内存 ELF 目录 `path` 匹配的 `arch_syscall_exec` 与 4 KiB 用户栈参数/环境变量布局（`sp` 16 字节对齐、`[sp] = argc`、`x0 = argc`、`x1 = argv`、`x2 = envp`），补齐 AArch64 `fork() + exec() + waitpid()` 进程生命周期三原语。

**Architecture:** `kernel/syscall/sys_native.c` 承载 `deep_copy_argv` 与 `sys_native_exec`，通过 `kernel/include/memory/uaccess.h` 的 `syscall_strnlen_user` 和 `copy_from_user_ft` 完成路径与 `argv`/`envp` 数组的内核堆深拷贝，再委托 `<arch/syscall.h>` 的 `arch_syscall_exec(ctx->arch_frame, path_copy, kargv, kenvp)`。成功时 `sys_native_exec` 置 `ctx->suppress_writeback = true` 以保留 AArch64 新镜像入口的 `regs->x0 = argc`（x86_64 `sys_exec` 在初始化新帧时显式置 `regs->rax = 0`）。AArch64 `arch_syscall_exec` 在 `owner->catalog` 中按 `path` 查找目标 ELF，先校验 4 KiB 栈与 `AARCH64_USER_STACK_HEADROOM = 512` 容量，再构造新 `struct aarch64_user_image`、向未发布的新栈页 `Phy_To_Virt(image->stack_pa)` 写入字符串与指针表，最后在关中断临界区内原子切换 `TTBR0_EL1`、`owner->image`、`t->mm`、`t->comm`、异常帧与 `tpidr_el0` 并销毁旧镜像。

**Tech Stack:** C11、AArch64 汇编、Clang/LLD、GNU Make、Python `unittest` 静态审计、宿主 C 单测、QEMU `virt,gic-version=3` / x86_64 E2E 测试。

**Spec:** [`docs/superpowers/specs/2026-11-14-aarch64-m4-exec-design.md`](../specs/2026-11-14-aarch64-m4-exec-design.md)

 * user address window.  When max == 0, validates that addr lies in the user
 * address window and returns 0 or -EFAULT.  When max > 0, returns 0..max

2. 在 `kernel/arch/x86_64/memory/uaccess.c` 尾部实现 `syscall_strnlen_user`（需包含 `<limits.h>`）：
```c
int syscall_strnlen_user(uint64_t addr, size_t max)
{
    if (!current || addr < X86_USER_MIN_ADDR || addr >= current->addr_limit)
        return -EFAULT;
    if (max == 0)
        return 0;
    if (max > (size_t)INT_MAX)
        return -EFAULT;
    size_t avail = (size_t)(current->addr_limit - addr);
    size_t limit = max < avail ? max : avail;
    int n = strnlen_user((const void *)(uintptr_t)addr, limit);
    if (n < 0)
        return -EFAULT;
    if ((size_t)n == limit && limit < max)
        return -EFAULT;
    return n;
}
```
3. 在 `kernel/arch/aarch64/memory/uaccess.c` 尾部实现 `syscall_strnlen_user`：
```c
int syscall_strnlen_user(uint64_t addr, size_t max)
{
    if (addr < AARCH64_USER_MIN || addr >= AARCH64_USER_LIMIT)
        return -EFAULT;
    if (max == 0)
        return 0;
    if (max > (size_t)INT_MAX)
        return -EFAULT;

    char buf[64];
    size_t scanned = 0;
    while (scanned < max) {
        uint64_t cur = addr + scanned;
        if (cur < addr || cur >= AARCH64_USER_LIMIT)
            return -EFAULT;
        size_t page_rem = (size_t)(PAGE_4K_SIZE - (cur & (PAGE_4K_SIZE - 1UL)));
        size_t chunk = max - scanned;
        if (chunk > page_rem)
            chunk = page_rem;
        if (chunk > sizeof(buf))
            chunk = sizeof(buf);
        if (copy_from_user_ft(buf, (const void *)(uintptr_t)cur, chunk) < 0)
            return -EFAULT;
        for (size_t j = 0; j < chunk; j++) {
            if (buf[j] == '\0')
                return (int)(scanned + j);
        }
        scanned += chunk;
    }
    return (int)max;
}
```
