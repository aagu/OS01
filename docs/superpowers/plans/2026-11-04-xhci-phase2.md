# xHCI Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement xHCI Phase 2: root port reset, slot allocation, device addressing, EP0 control transfers, and standard USB device descriptor enumeration on QEMU xHCI.

**Architecture:** Extend `kernel/driver/xhci.c` and `kernel/include/driver/xhci.h`. Implement a synchronous event filtering engine (`xhci_poll_event_filtered`) that safely consumes intervening asynchronous Port Status Change Events (Type 34). Implement port reset with RW1C protection, PED validation, and $T_{RSTRCY}$ delays. Support 32B and 64B context sizes (CSZ). Implement Enable Slot (Type 9) and Address Device (Type 11) commands with strictly aligned 4KB DMA page allocations (handling OS01 physical vs virtual addresses and rollback unwind on failure). Implement 3-stage control transfers on EP0 Transfer Rings (with Link TRB wrap at TRB 255) to retrieve and unpack 18-byte USB Device Descriptors.

**Tech Stack:** C (Clang, freestanding kernel runtime, -O2), x86_64 higher-half MMIO, QEMU xHCI emulation (`-device qemu-xhci,id=xhci -device usb-tablet,bus=xhci.0`), OS01 hosttest test harness.

**Spec:** `docs/superpowers/specs/2026-11-04-xhci-phase2-design.md`

## Global Constraints
- Freestanding C runtime: no standard libc headers in kernel space; use `<memory/slab.h>` (`kmalloc`/`kfree`), `<memory/pmm.h>` (`alloc_4k_page`/`free_4k_page`), `<log/log.h>`.
- **Memory Contract**: `alloc_4k_page()` returns physical address (`uint64_t`). Dereferencing requires `Phy_To_Virt(phys)`. `free_4k_page(phys)` accepts physical address (`uint64_t`). Passing a kernel virtual pointer to `free_4k_page` is forbidden.
- All register and TRB structures must be packed (`__attribute__((packed))`).
- Every `PORTSC` write must preserve RW1C bits using `(portsc & ~XHCI_PORTSC_RW1C_MASK)`.
- Event Ring polling must use `volatile` accesses to prevent compiler hoisting.
- `slot_id` is 1-based (`1..max_slots`); controller slot array must be sized `slots[XHCI_MAX_MANAGED_SLOTS + 1]`.
- All hosttests must run cleanly under `make test-host` without warnings or leaks.

## Review Focus
1. Intervening Type 34 (Port Status Change) event arriving on Event Ring during Command Completion (Type 33) or Transfer Event (Type 32) wait: must be consumed and acknowledged without hanging or aborting.
2. PORTSC register write clobbering RW1C bits (specifically `PED=1`), inadvertently disabling the port: must mask with `~XHCI_PORTSC_RW1C_MASK`.
3. Port reset exit where `PR=0` but `PED=0` (port failed to enable): must be detected and aborted before slot allocation.
4. CSZ context sizing: byte offset differences between 32B and 64B contexts in Input Context and Device Context.
5. EP0 Transfer Ring Link TRB wrap: TRB 255 Link TRB must have `TC=1` and cycle toggle on wrap.

void mock_xhci_write32(volatile void *addr, uint32_t val)
{
    uintptr_t offset = (uintptr_t)addr - (uintptr_t)s_mock_mmio;

    /* Operational registers start at 0x20. Port registers start at 0x20 + 0x400 = 0x420 */
    if ((const uint8_t *)addr >= s_mock_mmio &&
        (const uint8_t *)addr < s_mock_mmio + MOCK_MMIO_SIZE &&
        offset >= 0x420 && offset < 0x420 + 32 * 0x10) {

        uint32_t cur = *(volatile uint32_t *)addr;
        /* RW1C semantics: writing 1 clears bit, writing 0 leaves bit unchanged */
        uint32_t rw1c_cleared = cur & ~(val & XHCI_PORTSC_RW1C_MASK);
        /* Write control bits, preserve RO bits (CCS, Speed) and updated RW1C bits */
        uint32_t updated = (cur & XHCI_PORTSC_RO_MASK) |
                           (val & ~XHCI_PORTSC_RW1C_MASK & ~XHCI_PORTSC_RO_MASK) |
                           (rw1c_cleared & XHCI_PORTSC_RW1C_MASK);

        if (val & XHCI_PORTSC_PR) {
            updated &= ~XHCI_PORTSC_PR;
            updated |= XHCI_PORTSC_PRC;
            if (!s_inject_port_ped_fail) {
                updated |= XHCI_PORTSC_PED;
            } else {
                updated &= ~XHCI_PORTSC_PED;
            }
        }
        *(volatile uint32_t *)addr = updated;
        return;
    }

    *(volatile uint32_t *)addr = val;
}

    void *p = calloc(1, 4096);
    if (!p) return 0;
    s_mock_page_ptrs[s_mock_page_count++] = p;
    return (uint64_t)(uintptr_t)p;
}

void free_4k_page(uint64_t phys)
{
    void *ptr = (void *)(uintptr_t)phys;
    for (int i = 0; i < s_mock_page_count; i++) {

            free(ptr);
            s_mock_page_ptrs[i] = s_mock_page_ptrs[--s_mock_page_count];
            return;
        }
    }
}

void test_xhci_event_poll_with_intervening_port_change(void)
{
    TEST_CASE("Event polling: consume Type 34 and retrieve target Type 33");
    struct xhci_controller ctrl;
    memset(&ctrl, 0, sizeof(ctrl));
    struct xhci_trb event_ring[XHCI_TRB_RING_SIZE];
    memset(event_ring, 0, sizeof(event_ring));
    uint8_t rt_regs[0x100];
    memset(rt_regs, 0, sizeof(rt_regs));

    ctrl.event_ring_virt = event_ring;
    ctrl.event_ring_phys = 0x20000;
    ctrl.event_ring_dequeue = 0;
    ctrl.event_ring_cycle = 1;
    ctrl.rt_regs = rt_regs;

    /* Entry 0: Port Status Change Event (Type 34) */
    event_ring[0].parameter = 0;
    event_ring[0].status = 0;
    event_ring[0].control = (XHCI_TRB_TYPE_PORT_STATUS_EVT << 10) | 1; /* Cycle = 1 */

    /* Entry 1: Command Completion Event (Type 33, Slot 1, Success) */
    event_ring[1].parameter = 0x1000;
    event_ring[1].status = (XHCI_COMP_SUCCESS << 24);
    event_ring[1].control = (1U << 24) | (XHCI_TRB_TYPE_CMD_CMPL_EVT << 10) | 1; /* Cycle = 1 */

    struct xhci_trb evt;
    int rc = xhci_poll_event_filtered(&ctrl, XHCI_TRB_TYPE_CMD_CMPL_EVT, &evt, 100);
    assert_eq(rc, 0);
    assert_eq((evt.control >> 10) & 0x3F, XHCI_TRB_TYPE_CMD_CMPL_EVT);
    assert_eq((evt.control >> 24) & 0xFF, 1);
    assert_eq((evt.status >> 24) & 0xFF, XHCI_COMP_SUCCESS);
    assert_eq(ctrl.event_ring_dequeue, 2);

    /* Verify ERDP was updated with EHB bit set */
    uint64_t erdp = *(volatile uint64_t *)(rt_regs + 0x20 + XHCI_INTR_ERDP);
    assert_eq(erdp & ~XHCI_ERDP_EHB, 0x20000 + 2 * sizeof(struct xhci_trb));
    assert_true((erdp & XHCI_ERDP_EHB) != 0);
}
