# AArch64 M4.5 Implementation Plan

**Goal:** Suspend and resume two EL0 contexts with private address spaces.

**Architecture:** Reuse the existing ELF and synchronous exception frame. Keep one parked frame while the other runs. Publish both roots for the run, use the existing ASID-0 invalidation on each handoff, and restore the boot root before unpublishing them. The single-BSP probe runs before SMP with IRQs masked; it does not enter the scheduler.
