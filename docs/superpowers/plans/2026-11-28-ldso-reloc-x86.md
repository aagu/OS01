# ld.so 符号重定位(T2)实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把符号重定位从内核 exec 路径移交用户态 ld.so:动态链接主程序(PT_INTERP + DT_NEEDED)经 /lib/ld.so 装载 .so、SYSV hash 解析、应用 GLOB_DAT/JUMP_SLOT,端到端 exit(0)。

**Architecture:** 内核 elf_pie.c 白名单仅对带 interp 的主镜像放宽(exec 层加 ABI 门槛);ld.so 以 anon mmap + read + mprotect 装载依赖、自校验后应用重定位;四条 systest 用例(rc=0/95/126/98)+ 三层形状门钉住契约。

**Tech Stack:** C(lld 23,freestanding 夹具)、python3 checker、OS01 原生 int80(6 参 rdi/rsi/rdx/r10/r8/r9)、make。

**Spec:** [docs/superpowers/specs/2026-11-28-ldso-reloc-x86-design.md](../specs/2026-11-28-ldso-reloc-x86-design.md)(实施冲突以 spec 为准)

## Global Constraints

- 仅 x86_64;aarch64 全程不动(T4)。夹具/ldso 规则全部放在 `user/Makefile` 现有 x86 guard 内(T1 PT_INTERP 段,`INTERP_DIR` 起)。
- 一切动态链接产物钉死 `--hash-style=sysv -z now -z norelro -z max-page-size=4096 --pack-dyn-relocs=none`;只支持 DT_HASH(GNU-hash-only → ld.so exit 98)。
- 用户程序全部重新编译,无旧二进制兼容负担。
- marker 字符串逐字保留 T1:`[LDSO-ENTER]` / `OS01_LDSO`;新增 `[LDSO-RELOC]`、`[LDSO-ERR-*]`、`[DYN-T2]`。
- ld.so exit 码:91 直接 exec 防御(T1 保留)、95 缺库/open、96 符号未解析、97 未知重定位、98 形状/契约/校验违例、99 内部错误。
- 内核日志用 `debug_fs()` 等;ldso 串口输出用 raw `write(1, …)`(不用 serial_printk/color_printk)。
- 所有动态重定位公式按 spec:RELATIVE = bias + A;GLOB_DAT/JUMP_SLOT = S(定义方 bias + st_value;SHN_ABS = st_value),符号型 addend 必须 0。
- 不回改历史 spec/plan;roadmap/changelog 在闭环 Task 同步。
- 新宿主测试**不加新文件**(进 `hosttests/cases/test_elf_load_4k.c`),避免 test catalog 重生成;systest 用例注册进 `user/systest/systest.c` / `systest.h`。
- 每任务一提交;测试命令从仓库顶层跑;提交前 `git diff` 核对无并行会话混入的改动。

## Review Focus

1. **addend≠0 的符号型记录** → 拒绝不写错误地址。测试:Task 1 `test_pie_interp_symbolic_addend_rejected`。
2. **RELACOUNT 前缀错位**(总数对、前缀非 RELATIVE)→ 拒绝。测试:Task 1 `test_pie_interp_relacount_prefix_broken`。
3. **动态区无 DT_NULL 的 .so** → exit 98 而非缺页死亡。测试:Task 6 checker + Task 8 `dyn_link_baddyn` rc=98。
4. **T1 旧契约回归**(marker 顺序、握手对、直接 exec ld.so exit 91)→ 新 ld.so 不破坏。测试:Task 8 T1 用例回归。
5. **SHN_ABS 符号 S 不加 bias** → 夹具不自然产出,无自动化覆盖;Task 4 实施者自查 + changelog 记为已知未测项(T3 共享 libc 时补)。
