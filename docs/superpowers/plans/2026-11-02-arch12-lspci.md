# ARCH-12 lspci PCI 设备列举命令 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 内核把每个已枚举的 PCI 设备发布成 `/dev/pci/<BDF>/<attr>` 节点，用户态新增 `/bin/lspci` 按 Linux lspci 的格式列出这些设备。

**Architecture:** 内核新增 `kernel/bus/pci/pci_devfs.c` 模块，在 devfs 挂载后（`fs_boot_prepare()` 之后）把每个 PCI 设备的 7 个属性注册成 `/dev/pci/<BDF>/<attr>` 字符设备；用户态 `/bin/lspci` 用 `opendir`/`readdir` 枚举 `/dev/pci`，逐个读属性文件并按 Linux lspci 的格式输出。**零新增 syscall、零 UAPI 变更**——枚举完全走文件系统命名空间（这正是 ARCH-11 多级 devfs 路径的价值）。

**Tech Stack:** C（kernel，`clang` + `lld`）、repo 内 hosttest 框架（`hosttests/cases/` + `hosttests/mk/fs.mk`）、用户态 libc（`opendir`/`readdir`/`open`/`read`/`printf`/`strtoul`/`qsort`）。

**规格文档:** `docs/superpowers/specs/2026-11-02-arch12-lspci-design.md`

## Global Constraints

以下约束适用于**每一个** Task，实施时不得违反：

- **零新增 syscall、零 UAPI 变更**：不修改 `kernel/include/uapi/` 下任何文件，不新增/重排 `SYS_*` 号，不改 `boot_context` v2 ABI。
- **不修改** `kernel/fs/vfs.c`、`kernel/fs/devfs.c`、`kernel/bus/pci/core.c`、`kernel/arch/x86_64/bus/pci.c`、`kernel/include/bus/pci/pci.h`、`kernel/include/bus/pci/driver.h`。
- **不修改 `kernel/Makefile`**：`kernel/Makefile:133` 已用 `$(wildcard bus/pci/*.c)` 收集 PCI 源文件，新文件自动入构建。aarch64 profile 用的是**显式**源文件清单（`kernel/Makefile:70-99`，不含 `bus/pci/*`），故 aarch64 天然不编译本模块——与 ARCH-9「aarch64 不链接 PCI/NIC」的既有约定一致，无需 arch gate。
- **不修改 `config/rootfs.mk`**：`/bin/lspci` 由 `$(USER_PROGRAMS)` 自动派生（`config/rootfs.mk:4-5`）。
- **新增/修改的内核代码一律用 `log_err` / `log_warn` / `log_info`**；禁止裸 `serial_printk` / `color_printk`。
- **源目录 ↔ 头目录对称**：`kernel/bus/pci/pci_devfs.c` ↔ `kernel/include/bus/pci/pci_devfs.h`（AGENTS.md 目录规范 §1）。
- **`devfs_ops` 结构体布局不得改动**（设备 ABI）。属性上下文通过既有的 `devfs_get_private(node)` 取回。
- **`resource` 属性不输出 BAR 容量**：ARCH-9 契约明确 BAR 的无损 sizing 不可得，`length` 是驱动已知窗口而非 BAR 容量；编造 size 会给出误导性输出。只报地址与类型。
- **注册失败不阻断启动**：`-EEXIST` 视为幂等（节点已存在，**不记日志**），其它负 errno 用 `log_warn` 记录并从计数中扣除。
- **属性上下文对象永不释放**（延续 ARCH-10 §7.3「devfs 记录存活至关机」）；仅在注册失败时释放自己刚分配的那一个。
- **每个新增 hosttest case 必须在同一个 commit 里**完成：`hosttests/mk/fs.mk` 的 `register_host_test()` 注册 + `TEST_BINS` 条目 + 构建规则，三者缺一即为孤儿测试。
- **禁止在源码里出现 `TBD` / `TODO` / 占位实现。**
- 每完成一个 Task 立即 commit，不要攒到最后。

```c
// Does `dir` list an entry called `name` with the given type?
// type == 0 matches any type.
static bool readdir_has(vfs_node_t *dir, const char *name, uint8_t type)
{
    char name_buf[VFS_NAME_MAX];
    vfs_dirent_t entry;
    uint64_t idx = 0;
    while (1) {
        memset(&entry, 0, sizeof(entry));
        entry.name = name_buf;
        if (dir->f_ops->readdir(dir, idx++, &entry) != 0) return false;
        if (entry.name[0] == '\0') return false;
        if (strcmp(entry.name, name) == 0)
            return type == 0 || entry.type == type;
    }
}
```

### Step 3: 写 `kernel/include/bus/pci/pci_devfs.h`

```c
/* kernel/include/bus/pci/pci_devfs.h — PCI devices published in the devfs namespace
 *
 * ARCH-12: every enumerated PCI device is published as
 * /dev/pci/<BDF>/<attr> so that user space can enumerate the PCI bus
 * with plain directory reads — no new syscall, no UAPI change.
 */
#ifndef _BUS_PCI_PCI_DEVFS_H
#define _BUS_PCI_PCI_DEVFS_H

#include <stdint.h>
#include <stddef.h>
#include <bus/pci/pci.h>

// Attribute ids — the order matches the registration table in pci_devfs.c.
typedef enum {
    PCI_ATTR_VENDOR = 0,
    PCI_ATTR_DEVICE,
    PCI_ATTR_CLASS,
    PCI_ATTR_CONFIG,
    PCI_ATTR_RESOURCE,
    PCI_ATTR_IRQ,
    PCI_ATTR_DRIVER,
    PCI_ATTR_COUNT,
} pci_attr_id_t;

// Register /dev/pci/<BDF>/<attr> for every enumerated PCI device.
// Returns the number of attribute nodes published, or a negative errno.
// Safe to call once after devfs is mounted; a second call is a no-op that
// returns the published count.
int pci_devfs_register_all(void);

// Register /dev/pci/<BDF>/<attr> for ONE device.  Exposed so the host test
// can publish a synthetic device without a PCI enumeration.
// Returns the number of attribute nodes PRESENT after the call (an
// already-existing node counts as present, so the call is idempotent), or a
// negative errno for an invalid argument.
int pci_devfs_register_device(const struct pci_device *pdev);

// Render one attribute of one device into `buf` (raw bytes, NOT
// NUL-terminated).  Returns the TOTAL content length in bytes — which may
// exceed `size` when the content was truncated, so the caller always
// learns the stream length — or a negative errno.
int pci_devfs_format_attr(const struct pci_device *pdev, pci_attr_id_t attr,
                           char *buf, size_t size);

#endif /* _BUS_PCI_PCI_DEVFS_H */
```

```c
/* kernel/bus/pci/pci_devfs.c — publish PCI devices in the devfs namespace
 *
 * ARCH-12.  Every enumerated PCI device becomes
 * /dev/pci/<BDF>/<attr> where <BDF> is "dddd:dd:dd.d" and <attr> is one of
 * vendor / device / class / config / resource / irq / driver.  User space
 * enumerates the bus with opendir()/readdir() — no new syscall and no UAPI
 * change, because ARCH-11 gave devfs multi-component registration paths.
 *
 * The attribute CONTENT is produced by pci_devfs_format_attr(); the devfs
 * nodes are produced by pci_devfs_register_device() / pci_devfs_register_all().
 */
#include <bus/pci/pci_devfs.h>
#include <bus/pci/driver.h>
#include <log/log.h>
#include <stdio.h>
#include <string.h>
#include <errno.h>

// Size of the stack buffer the read callback renders one attribute into.
// It must cover the largest attribute content: the configuration space is
// exactly 256 bytes and the BAR list is at most 6 lines of 42 bytes (252).
// 320 leaves headroom while keeping the read callback's stack frame below
// the kernel's -Wframe-larger-than=512 budget.
#define PCI_DEVFS_FMT_MAX   320

// PCI configuration space length in bytes.
#define PCI_DEVFS_CFG_LEN   256

// ── Individual attribute renderers ────────────────────────────
// Each returns the CONTENT length (snprintf semantics: the returned
// length is the full length even when the buffer was too small), or a
// negative errno.

static int fmt_vendor(const struct pci_device *pdev, char *buf, size_t size)
{
    int n = snprintf(buf, size, "0x%04x\n", (unsigned)(pdev->vendor & 0xffffu));
    return (n < 0) ? -EIO : n;
}

static int fmt_device(const struct pci_device *pdev, char *buf, size_t size)
{
    int n = snprintf(buf, size, "0x%04x\n", (unsigned)(pdev->device & 0xffffu));
    return (n < 0) ? -EIO : n;
}

static int fmt_class(const struct pci_device *pdev, char *buf, size_t size)
{
    int n = snprintf(buf, size, "0x%06x\n", (unsigned)(pdev->class_code & 0xffffffu));
    return (n < 0) ? -EIO : n;
}

static int fmt_irq(const struct pci_device *pdev, char *buf, size_t size)
{
    uint32_t gsi = 0;
    if (pci_route_gsi(pdev, &gsi) != 0) {
        int n = snprintf(buf, size, "none\n");
        return (n < 0) ? -EIO : n;
    }
    int n = snprintf(buf, size, "%u\n", (unsigned)gsi);
    return (n < 0) ? -EIO : n;
}

static int fmt_driver(const struct pci_device *pdev, char *buf, size_t size)
{
    const char *name = (pdev->driver && pdev->driver->name) ? pdev->driver->name : "none";
    int n = snprintf(buf, size, "%s\n", name);
    return (n < 0) ? -EIO : n;
}

// The BAR list.  Only the ADDRESS and the KIND are reported: the BAR
// capacity is not knowable without a destructive sizing probe, and the
// ARCH-9 driver-model contract forbids that — a BAR "length" there is the
// window the driver knows, not the BAR capacity.  Reporting a fabricated
// size would be misleading, so the "(size=...)" field Linux prints is
// deliberately omitted.
static int fmt_resource(const struct pci_device *pdev, char *buf, size_t size)
{
    size_t off = 0;
    int total = 0;

    for (int i = 0; i < 6; i++) {
        const struct pci_bar *bar = &pdev->bars[i];
        if (!bar->valid) continue;

        const char *kind;
        switch (bar->kind) {
        case PCI_BAR_IO:              kind = "I/O ports"; break;
        case PCI_BAR_MMIO32:
        case PCI_BAR_MMIO64:          kind = "Memory";    break;
        default:                      continue;   /* NONE / UPPER half */
        }

        size_t remain = (off < size) ? (size - off) : 0;
        int n = snprintf((off < size) ? (buf + off) : NULL, remain,
                         "Region %d: %s at 0x%llx\n", i, kind,
                         (unsigned long long)bar->address);
        if (n < 0) return -EIO;
        total += n;
        off += (size_t)n;
    }
    return total;
}

// The raw 256-byte configuration space, little-endian, exactly as the
// hardware returns it.
static int fmt_config(const struct pci_device *pdev, char *buf, size_t size)
{
    size_t want = (size < PCI_DEVFS_CFG_LEN) ? size : PCI_DEVFS_CFG_LEN;

    for (size_t i = 0; i < want; i += 4) {
        uint32_t dword = 0;
        int rc = pci_config_read32(pdev, (uint16_t)i, &dword);
        if (rc != 0) return rc;
        uint8_t b[4] = {
            (uint8_t)(dword & 0xffu),
            (uint8_t)((dword >> 8) & 0xffu),
            (uint8_t)((dword >> 16) & 0xffu),
            (uint8_t)((dword >> 24) & 0xffu),
        };
        for (size_t k = 0; k < 4 && (i + k) < want; k++) {
            buf[i + k] = (char)b[k];
        }
    }
    return PCI_DEVFS_CFG_LEN;
}

// ── Public formatting entry point ─────────────────────────────
int pci_devfs_format_attr(const struct pci_device *pdev, pci_attr_id_t attr,
                           char *buf, size_t size)
{
    if (!pdev || !buf) return -EINVAL;
    if ((unsigned)attr >= (unsigned)PCI_ATTR_COUNT) return -EINVAL;

    switch (attr) {
    case PCI_ATTR_VENDOR:   return fmt_vendor(pdev, buf, size);
    case PCI_ATTR_DEVICE:   return fmt_device(pdev, buf, size);
    case PCI_ATTR_CLASS:    return fmt_class(pdev, buf, size);
    case PCI_ATTR_CONFIG:   return fmt_config(pdev, buf, size);
    case PCI_ATTR_RESOURCE: return fmt_resource(pdev, buf, size);
    case PCI_ATTR_IRQ:      return fmt_irq(pdev, buf, size);
    case PCI_ATTR_DRIVER:   return fmt_driver(pdev, buf, size);
    default:                return -EINVAL;
    }
}
```

```c
// ── devfs publication ─────────────────────────────────────────

// Per-attribute context: the devfs node's private_data.  One context
// per attribute node — the node has to know WHICH attribute it serves.
typedef struct pci_attr_ctx {
    struct pci_device *pdev;
    uint8_t            attr;      // pci_attr_id_t
} pci_attr_ctx_t;

static const char *const s_attr_names[PCI_ATTR_COUNT] = {
    "vendor", "device", "class", "config", "resource", "irq", "driver",
};

// One devfs_ops table for every attribute; the read callback dispatches
// on the context's attribute id.
static int pci_attr_read(vfs_node_t *node, uint64_t offset, uint64_t size,
                          void *buffer)
{
    pci_attr_ctx_t *ctx = (pci_attr_ctx_t *)devfs_get_private(node);
    if (!ctx || !ctx->pdev || !buffer) return -EINVAL;
    if (size == 0) return 0;

    char tmp[PCI_DEVFS_FMT_MAX];
    int len = pci_devfs_format_attr(ctx->pdev, (pci_attr_id_t)ctx->attr,
                                     tmp, sizeof(tmp));
    if (len < 0) return len;
    if (offset >= (uint64_t)len) return 0;

    uint64_t avail = (uint64_t)len - offset;
    uint64_t n = (size < avail) ? size : avail;
    memcpy(buffer, tmp + offset, n);
    return (int)n;
}

static const struct devfs_ops pci_attr_ops = {
    .read = pci_attr_read,
};

// Publish /dev/pci/<BDF>/<attr> for one device.  Returns the number of
// attribute nodes present afterwards; an already-existing node counts as
// present, so the call is idempotent.
int pci_devfs_register_device(const struct pci_device *pdev)
{
    if (!pdev) return -EINVAL;

    char bdf[PCI_DEVFS_BDF_MAX];
    int n = snprintf(bdf, sizeof(bdf), "%04x:%02x:%02x.%u",
                     (unsigned)pdev->domain, (unsigned)pdev->bus,
                     (unsigned)pdev->slot, (unsigned)pdev->fn);
    if (n < 0 || (size_t)n >= sizeof(bdf)) return -EINVAL;

    int published = 0;
    for (int i = 0; i < PCI_ATTR_COUNT; i++) {
        char path[PCI_DEVFS_PATH_MAX];
        int pn = snprintf(path, sizeof(path), "%s/%s/%s",
                          PCI_DEVFS_NAMESPACE, bdf, s_attr_names[i]);
        if (pn < 0 || (size_t)pn >= sizeof(path)) {
            log_warn("pci_devfs: path too long for attribute '%s'\n",
                     s_attr_names[i]);
            continue;
        }

        pci_attr_ctx_t *ctx = (pci_attr_ctx_t *)kmalloc(sizeof(*ctx));
        if (!ctx) {
            log_warn("pci_devfs: out of memory for '%s'\n", path);
            continue;
        }
        ctx->pdev = (struct pci_device *)pdev;
        ctx->attr = (uint8_t)i;

        int rc = devfs_register_path(path, ctx, &pci_attr_ops);
        if (rc == 0) {
            published++;
        } else if (rc == -EEXIST) {
            // Already published (idempotent re-registration): the node is
            // present but keeps the context it was created with, so ours
            // is dead weight and must not be leaked.
            kfree(ctx);
            published++;
        } else {
            log_warn("pci_devfs: register '%s' failed (%d)\n", path, rc);
            kfree(ctx);
        }
    }
    return published;
}

static bool s_pci_devfs_registered = false;
static int  s_pci_devfs_published = 0;

// Publish the whole bus.  Called once from the kernel boot path after
// devfs is mounted; a second call is a no-op that returns the count.
int pci_devfs_register_all(void)
{
    if (s_pci_devfs_registered) return s_pci_devfs_published;

    unsigned int count = pci_device_count();
    int total = 0;
    for (unsigned int i = 0; i < count; i++) {
        struct pci_device *pdev = pci_device_get(i);
        if (!pdev) continue;
        int r = pci_devfs_register_device(pdev);
        if (r > 0) total += r;
    }

    s_pci_devfs_published = total;
    s_pci_devfs_registered = true;
    log_info("pci_devfs: published %d attribute nodes for %u PCI devices\n",
             total, count);
    return total;
}
```

```c
// lspci — list the PCI devices published under /dev/pci
//
// ARCH-12.  The kernel publishes every enumerated PCI device as
// /dev/pci/<BDF>/<attr>; this program enumerates that namespace with
// plain directory reads and prints one summary line per device, in the
// same shape as Linux lspci:
//
//   00:1f.2 SATA controller: Intel Corporation 82801IR/IO/IH SATA AHCI Controller (rev 00)
//

static const char *class_name(uint32_t class_code)
{
    uint8_t base = (uint8_t)((class_code >> 16) & 0xffu);
    uint8_t sub  = (uint8_t)((class_code >> 8) & 0xffu);

    for (size_t i = 0; i < sizeof(kClassNames) / sizeof(kClassNames[0]); i++) {
        if (kClassNames[i].base == base && kClassNames[i].sub == sub)
            return kClassNames[i].name;
    }
    for (size_t i = 0; i < sizeof(kClassBase) / sizeof(kClassBase[0]); i++) {
        if (kClassBase[i].base == base)
            return kClassBase[i].name;
    }
    return NULL;
}

static const char *class_base_short(uint32_t class_code)

// Compose the "vendor device" part of the summary line.
//   - numeric:        "8086:2922"
//   - both known:     "Intel Corporation 82801IR/IO/IH SATA AHCI Controller"
//   - vendor known:   "Intel Corporation 2922"
//   - neither known:  "8086 2922"
static void format_ids(char *out, size_t size, uint16_t vendor, uint16_t device,
                       bool numeric)
{
    if (numeric) {
        snprintf(out, size, "%04x:%04x", vendor, device);
        return;
    }
    const char *vname = vendor_name(vendor);
    const char *dname = device_name(vendor, device);
    if (vname && dname)
        snprintf(out, size, "%s %s", vname, dname);
    else if (vname)
        snprintf(out, size, "%s %04x", vname, device);
    else
        snprintf(out, size, "%04x %04x", vendor, device);
}

// ── Attribute access ─────────────────────────────────────────

// Read one attribute file into `buf`.  Returns the byte count, or -1.
// The loop keeps reading until the buffer is full or the device reports
// EOF, so a short read never truncates the content.
static int read_attr(const char *bdf, const char *attr, char *buf, size_t size)
{
    char path[PATH_BUF_MAX];
    snprintf(path, sizeof(path), "%s/%s/%s", PCI_NS, bdf, attr);

    int fd = open(path, O_RDONLY);
    if (fd < 0) return -1;

    size_t total = 0;
    while (total < size) {
        int64_t n = read(fd, buf + total, size - total);
        if (n <= 0) break;
        total += (size_t)n;
    }
    close(fd);
    return (int)total;
}

// Read an attribute and parse it as a hexadecimal number.  Returns false
// when the attribute is missing or unparsable.
static bool read_attr_hex(const char *bdf, const char *attr, uint32_t *out)
{
    char buf[ATTR_BUF_MAX];
    int n = read_attr(bdf, attr, buf, sizeof(buf) - 1);
    if (n <= 0) return false;
    buf[n] = '\0';
    char *end = NULL;
    unsigned long v = strtoul(buf, &end, 0);
    if (end == buf) return false;
    *out = (uint32_t)v;
    return true;
}

// ── Device rendering ─────────────────────────────────────────

static void print_device(const char *bdf, bool numeric, bool verbose, bool hexdump)
{
    uint32_t vendor = 0, device = 0, class_code = 0;
    bool have_ids = read_attr_hex(bdf, "vendor", &vendor) &&
                    read_attr_hex(bdf, "device", &device);
    bool have_class = read_attr_hex(bdf, "class", &class_code);

    // The configuration space is read once and reused for the revision
    // byte and the optional hex dump.
    char config[CONFIG_BUF_MAX];
    int config_len = read_attr(bdf, "config", config, sizeof(config));

    // "0000:00:1f.2" -> "00:1f.2" (the domain is dropped, like Linux lspci)
    char slot[32];
    const char *colon = strchr(bdf, ':');
    snprintf(slot, sizeof(slot), "%s", colon ? colon + 1 : bdf);

    char class_buf[64];
    if (have_class) {
        const char *cn = class_name(class_code);
        if (cn)
            snprintf(class_buf, sizeof(class_buf), "%s", cn);
        else
            snprintf(class_buf, sizeof(class_buf), "Unknown class [%02X%02X%02X]",
                     (class_code >> 16) & 0xffu, (class_code >> 8) & 0xffu,
                     class_code & 0xffu);
    } else {
        snprintf(class_buf, sizeof(class_buf), "Unknown class");
    }

    char ids[128];
    if (have_ids)
        format_ids(ids, sizeof(ids), (uint16_t)vendor, (uint16_t)device, numeric);
    else
        snprintf(ids, sizeof(ids), "????:????");

    char rev[8];
    if (config_len >= 9)
        snprintf(rev, sizeof(rev), "%02x", (unsigned char)config[0x08]);
    else
        snprintf(rev, sizeof(rev), "??");

    printf("%s %s: %s (rev %s)\n", slot, class_buf, ids, rev);

    if (verbose) {
        uint8_t base = (uint8_t)((class_code >> 16) & 0xffu);
        uint8_t sub  = (uint8_t)((class_code >> 8) & 0xffu);
        uint8_t prog = (uint8_t)(class_code & 0xffu);
        const char *sub_short = class_sub_short(class_code);
        if (sub_short)
            printf("\tClass: %s, subclass: %s, ProgIF: %02x\n",
                   class_base_short(class_code), sub_short, prog);
        else
            printf("\tClass: %s, subclass: 0x%02x, ProgIF: %02x\n",
                   class_base_short(class_code), sub, prog);

        char irq[ATTR_BUF_MAX];
        int irq_len = read_attr(bdf, "irq", irq, sizeof(irq) - 1);
        if (irq_len > 0) {
            irq[irq_len] = '\0';
            // Strip the trailing newline the kernel emits.
            for (int i = irq_len - 1; i >= 0; i--) {
                if (irq[i] == '\n') { irq[i] = '\0'; break; }
            }
        } else {
            snprintf(irq, sizeof(irq), "none");
        }
        printf("\tIRQ: %s\n", irq);

        char drv[ATTR_BUF_MAX];
        int drv_len = read_attr(bdf, "driver", drv, sizeof(drv) - 1);
        if (drv_len > 0) {
            drv[drv_len] = '\0';
            for (int i = drv_len - 1; i >= 0; i--) {
                if (drv[i] == '\n') { drv[i] = '\0'; break; }
            }
        } else {
            snprintf(drv, sizeof(drv), "none");
        }
        printf("\tKernel driver in use: %s\n", drv);

        char res[512];
        int res_len = read_attr(bdf, "resource", res, sizeof(res) - 1);
        if (res_len > 0) {
            res[res_len] = '\0';
            for (int i = 0; i < res_len; i++) {
                if (res[i] == '\n') {
                    res[i] = '\0';
                    printf("\t%s\n", res);
                    res[0] = '\0';
                }
            }
            if (res[0] != '\0') printf("\t%s\n", res);
        }
    }

    if (hexdump) {
        if (config_len <= 0) {
            printf("\tconfig space unavailable\n");
        } else {
            for (int off = 0; off < config_len; off += 16) {
                printf("%02x:", off);
                for (int i = 0; i < 16; i++) {
                    if (off + i < config_len)
                        printf(" %02x", (unsigned char)config[off + i]);
                    else
                        printf("   ");
                }
                printf("\n");
            }
        }
    }
}

// ── Entry point ──────────────────────────────────────────────

static int cmp_bdf(const void *a, const void *b)
{
    return strcmp((const char *)a, (const char *)b);
}

static void usage(void)
{
    printf("usage: lspci [-x] [-n] [-v] [-h]\n");
    printf("  -x  also dump the 256-byte configuration space\n");
    printf("  -n  do not resolve names (numeric vendor:device ids)\n");
    printf("  -v  verbose: class breakdown, IRQ, driver and BAR regions\n");
    printf("  -h  this help\n");
}

int main(int argc, char **argv)
{
    bool numeric = false, verbose = false, hexdump = false;

    for (int i = 1; i < argc; i++) {
        if (argv[i][0] != '-' || argv[i][1] == '\0') {
            usage();
            return 2;
        }
        for (const char *p = argv[i] + 1; *p; p++) {
            switch (*p) {
            case 'x': hexdump = true; break;
            case 'n': numeric = true; break;
            case 'v': verbose = true; break;
            case 'h': usage(); return 0;
            default:
                usage();
                return 2;
            }
        }
    }

    DIR *dir = opendir(PCI_NS);
    if (!dir) {
        fprintf(stderr, "lspci: cannot open %s\n", PCI_NS);
        return 1;
    }

    static char bdfs[MAX_DEVICES][32];
    int count = 0;

    struct dirent *ent;
    while ((ent = readdir(dir)) != NULL) {
        if (ent->d_type != DT_DIR) continue;
        if (ent->d_name[0] == '.') continue;
        if (count >= MAX_DEVICES) break;
        snprintf(bdfs[count], sizeof(bdfs[0]), "%s", ent->d_name);
        count++;
    }
    closedir(dir);

    if (count == 0) {
        fprintf(stderr, "lspci: no PCI devices found under %s\n", PCI_NS);
        return 1;
    }

    qsort(bdfs, (size_t)count, sizeof(bdfs[0]), cmp_bdf);

    for (int i = 0; i < count; i++)
        print_device(bdfs[i], numeric, verbose, hexdump);

    return 0;
}
```

```markdown
### PCI 设备命名空间（ARCH-12）

内核启动时（`fs_boot_prepare()` 之后）把每个已枚举的 PCI 设备发布成
`/dev/pci/<BDF>/<attr>`：

| 路径 | 内容 |
|------|------|
| `/dev/pci/0000:00:1f.2/vendor` | vendor id，文本 `"0x8086\n"` |
| `/dev/pci/0000:00:1f.2/device` | device id，文本 `"0x2922\n"` |
| `/dev/pci/0000:00:1f.2/class` | 24-bit class code，文本 `"0x010601\n"` |
| `/dev/pci/0000:00:1f.2/config` | 256 字节原始 config space |
| `/dev/pci/0000:00:1f.2/resource` | BAR 列表（每行 `Region N: <kind> at 0x<addr>`） |
| `/dev/pci/0000:00:1f.2/irq` | 路由后的 GSI，文本 `"16\n"`；取不到时 `"none\n"` |
| `/dev/pci/0000:00:1f.2/driver` | 绑定的驱动名；未绑定时 `"none\n"` |

- `<BDF>` 是 `domain:bus:slot.function`（如 `0000:00:1f.2`）。
- `resource` **只报地址与类型，不报 BAR 容量**——BAR 的无损 sizing 不可得
  （ARCH-9 驱动模型契约），编造 size 会给出误导性输出。
- 该命名空间由 `kernel/bus/pci/pci_devfs.c` 发布，用户态用 `opendir`/`readdir`
  枚举，**不新增任何 syscall**。用户态命令见 `/bin/lspci`。
```
