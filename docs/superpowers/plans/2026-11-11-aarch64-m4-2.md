# AArch64 M4.2 Implementation Plan

**Goal:** Let the existing M4.1 SVC probe safely read and write a user buffer.

**Architecture:** Reuse the M3 page-table walk for range preflight. Copy with byte-sized unprivileged loads/stores in the active private TTBR0. Recover a matching same-EL data abort only at those two instructions; all other EL1 sync exceptions keep the fatal path.

**Scope:** Pre-SMP M4.1 probe, frozen user mappings, no VMA, COW, syscall ABI, or normal-image user tasks.

- [x] Extend the existing EL0 case with a cross-page SVC and see it fail without the copy backend.
- [x] Implement the range adapter and checked copies with narrowly scoped fault recovery.
- [x] Verify success, preflight rejection, and real read/write abort recovery in one single-core QEMU boot. Run the existing EL1 fatal-fault check.

Verification: the existing single-core suite passed 15/15 with the new SVC path, including real EL1 load and store aborts. The existing `MODE=sync-fault` regression observed the expected fatal diagnostic.
