# AArch64 M4.4 Implementation Plan

**Goal:** Resume the probe ELF after real EL0 timer interrupts.

**Architecture:** Reuse the high Device aliases, existing GIC dispatch/EOI, and shared IRQ save/restore. Run the new check after timer startup and before scheduling on a single CPU. Retain the original early ELF check.

- [x] Add a bounded EL0 wait case that fails with no user IRQ delivery.
- [x] Admit EL0t IRQ frames in the probe image, preserve private TTBR0 and enable IRQ only on the designated EL0 entry.
- [x] Boot the same single-core selftest image; require two real lower-EL timer ticks, register/stack preservation and SVC exit.
