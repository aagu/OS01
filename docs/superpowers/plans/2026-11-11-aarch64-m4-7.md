# AArch64 M4.7 Implementation Plan

**Goal:** Launch and reclaim one private EL0 ELF through the existing BSP scheduler.

**Architecture:** A pinned kernel worker owns the ELF mappings and enters EL0 on its own kernel stack. A synchronous SVC returns to the worker, which restores the boot root before destroying the mappings and returning the exit code to the normal kthread exit path. The EL0 leg is IRQ-masked; ordinary AArch64 images still have no userspace support.

- [x] Register a late scheduler case, start the worker and a later witness thread, and observe rejection by the old boot-only EL0 runner.
- [x] Admit a single scheduled BSP kernel worker to the probe and verify its active root, SVC exit code, boot state restoration, user page baseline, and real kthread reaping.
- [x] Run the existing single-core QEMU selftest and confirm the ordinary image excludes the scheduled probe.

Verification: the boot-only runner rejected the scheduled worker before its first SVC (18/19). The scheduled runner passed the same single-core boot (19/19), and the ordinary UEFI image built without the probe symbols.
