# LVGL v9.5.0 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将开源嵌入式图形库 LVGL v9.5.0 移植到 OS01 用户态环境中，接入 single-writer sysroot 构建系统，并提供 `/bin/test_lvgl` 兼容性测试程序验证离屏软件渲染与内存池状态。

**Architecture:** 
`thirdpart/lvgl` 注册为 Git submodule 并由 `thirdpart/lvgl.manifest` 锁定 commit；
`config/lv_conf.h` 定制 OS01 单线程、TLSF 内存池（4MB）、软件渲染与 XRGB8888 格式；
`liblvgl/Makefile` 编译 `src/**/*.c` 输出 `usr/lib/liblvgl.a` 与 `usr/include/lvgl/` 到 staging 树；
`mk/components/sysroot.mk` 聚合发布至 sysroot generation；
`user/test_lvgl.c` 经 sysroot 编译为 `/bin/test_lvgl` 打包进 ext2 根文件系统，在 QEMU 内验证滴答推进、控件渲染、像素取样和内存池指标。

**Tech Stack:** C99/C11、x86_64 裸机目标（freestanding）、LLVM/Clang、GNU Make、LVGL v9.5.0、ext2 根文件系统、QEMU。

**Spec:** `docs/superpowers/specs/2026-10-06-lvgl-port-design.md`（执行前必须阅读）。

## Global Constraints

- **代码基准与版本**：OS01 基线 `62f9cac76ff7734d4444cf04b748dfc003554452`；LVGL v9.5.0 (`85aa60d18b3d5e5588d7b247abf90198f07c8a63`)。
- **Sysroot 单写者原则**：只有 `mk/components/sysroot.mk` 能够向 sysroot generation 写入；`liblvgl/Makefile` 仅输出到 `$(INSTALL_ROOT)`（staging 目录）并生成 manifest。
- **应用头文件隔离**：用户态应用通过 `-I$(TARGET_INCDIR)/lvgl -DLV_CONF_INCLUDE_SIMPLE` 引用已发布的头文件，严禁穿透引用源码目录。
- **无外部未决符号**：`liblvgl.a` 对象合并后只能依赖 OS01 `libc.a` 导出的符号集合；严禁引入 libm（如 `cosf/sinf/tanf`）及 pthread 外部符号。
- **独立验证**：本阶段不修改 `user/desktop.c`，测试程序 `/bin/test_lvgl` 采用纯离屏内存渲染，不链接 `-lgfx`。

## Review Focus

以下五类潜在失效模式必须在计划任务中通过具体断言或验证步骤锁定：

1. **时钟递增假阳性（Task 5）**：`clock_gettime()` 失败返回 0 导致无符号差值溢出变大而被误判为递增 → 通过 `clock_failed` 标志并在独立等待预算内断言 `0 < (uint32_t)(t1 - t0) <= 100`。
2. **像素采样未命中（Task 5）**：flush 回调仅覆盖了部分区域而漏采目标点 → 必须设置 `bg_sampled` 与 `btn_sampled` 双重标记，测试收尾时强制断言两点均被命中。
3. **行跨度异常对齐（Task 5）**：绘制缓冲带有非预期行填充字节导致像素寻址错位 → 显式断言行跨度 `stride_bytes == area_w * 4` 并按字节偏移定位像素比较低 24 位 RGB。
4. **Staging 旧头文件残留（Task 3）**：删改头文件后 staging 目录残留孤立文件污染发布 → `install` 目标先安全校验路径再执行 `rm -rf $(INSTALL_ROOT)`。
5. **增量配置更新失效（Task 3）**：修改 `config/lv_conf.h` 后未重新编译源文件或未重新发布 sysroot → 使用 `-MMD -MP` 头文件依赖并校验 sysroot receipt 变化。
