# LVGL v9.5.0 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将开源嵌入式图形库 LVGL v9.5.0 移植到 OS01 用户态环境中，接入 single-writer sysroot 构建系统，并通过 `/bin/test_lvgl` 兼容性测试程序在 QEMU 内严格验证离屏软件渲染、像素精确匹配与 TLSF 内存池状态。

**Architecture:** 
`thirdpart/lvgl` 注册为 Git submodule 并由 `thirdpart/lvgl.manifest` 锁定 commit；
`config/lv_conf.h` 定制 OS01 单线程、TLSF 内存池（4MB）、软件渲染与 XRGB8888 格式；
`liblvgl/Makefile` 校验 manifest commit 后，保持相对路径结构编译所有 `.c`，只将 `.h` 头文件及许可证与 `liblvgl.a` 暂存至 staging 树；
`mk/components/sysroot.mk` 聚合发布至 sysroot generation；
`user/test_lvgl.c` 经 sysroot 编译为 `/bin/test_lvgl` 打包进 ext2 根文件系统；
`qemutests/test_lvgl_runner.py` 自动化驱动 QEMU，使用 `selectors` 非阻塞分块累积、以防回显假阳性的握手与双阶段超时（25s 启动就绪 + 10s 执行验证）严格验证单调时钟推进、控件渲染、像素取样和内存池指标。

**Tech Stack:** C99/C11、x86_64 裸机目标（freestanding）、LLVM/Clang、GNU Make、LVGL v9.5.0、ext2 根文件系统、Python 3 / QEMU。

**Spec:** `docs/superpowers/specs/2026-10-06-lvgl-port-design.md`（执行前必须阅读）。

## Global Constraints

- **代码基准与版本**：OS01 基线 `62f9cac76ff7734d4444cf04b748dfc003554452`；LVGL v9.5.0 (`85aa60d18b3d5e5588d7b247abf90198f07c8a63`)。
- **Manifest 强约束**：`liblvgl/Makefile` 必须读取 `thirdpart/lvgl.manifest`，校验 `thirdpart/lvgl` 源码存在且 HEAD 等于 `LVGL_REVISION`（兼容 `.git` 文件与目录），由 `.PHONY: check-version` 作为所有对象文件的 order-only 前置，杜绝源码版本漂移。
- **构建目录规范**：在 `mk/profiles/x86_64-clang.mk` 中显式定义 `LIBLVGL_BUILD_DIR := $(BUILD_DIR)/liblvgl`，组件构建严格在此目录下进行。
- **Sysroot 单写者原则**：只有 `mk/components/sysroot.mk` 能够向 sysroot generation 写入；`liblvgl/Makefile` 仅输出到 `$(INSTALL_ROOT)`（staging 目录）并生成 manifest。
- **头文件纯净性**：include 目录只发布 `.h` 头文件及许可证文件，严禁将 `.c` 源文件复制进 sysroot include 树。
- **应用头文件隔离**：用户态应用通过 `-I$(TARGET_INCDIR)/lvgl -DLV_CONF_INCLUDE_SIMPLE` 引用已发布的头文件，包含 `<sys/time.h>` 引用 `clock_gettime`，严禁穿透引用源码目录。
- **零未解析符号**：`liblvgl.a` 所有对象合并后与 OS01 `libc.a` 做可重定位链接，外部未解析符号必须严格为 0（无 compiler-rt/canary/libm/pthread 遗留）。
- **独立验证**：本阶段不修改 `user/desktop.c`，测试程序 `/bin/test_lvgl` 采用纯离屏内存渲染，不链接 `-lgfx`。

## Review Focus

以下五类潜在失效模式必须在计划任务中通过具体断言或验证步骤锁定：

1. **时钟递增假阳性与回绕（Task 5）**：`clock_gettime()` 失败返回 0 导致无符号差值溢出变大而被误判为递增 → 通过 `clock_failed` 标志并在最多 50 次微量延时中，一旦观测到 `0 < (uint32_t)(t1 - t0) <= 100` 即判定成功；失败或超时非零退出。
2. **像素采样未命中（Task 5）**：flush 回调仅覆盖了部分区域而漏采目标点 → 设置 `bg_sampled` 与 `btn_sampled` 双重标记，测试收尾时强制断言两点均被命中。
3. **行跨度异常对齐（Task 5）**：绘制缓冲带有非预期行填充字节导致像素寻址错位 → 从活动 draw buffer 获取 `header.stride`，断言 `stride == area_w * 4` 并按字节偏移定位像素比较低 24 位 RGB。
4. **终端输入回显被误判为握手执行（Task 6）**：直接发送 `echo __SHELL_CANARY__` 会在终端回显中匹配该字串导致假阳性 → 发送 `printf '__SHELL_%s__\n' CANARY` 使输入命令不含目标标记，并在发送后的独立分块中匹配完整行 `__SHELL_CANARY__`，消耗同一启动 25s 预算。
5. **阻塞读取与超时失控（Task 6）**：阻塞式 `readline()` 在 QEMU 无输出或 prompt 无换行时永久挂起 → `qemutests/test_lvgl_runner.py` 使用 `selectors` 分块读取、`time.monotonic()` 严格实施 25s 启动与 10s 执行超时，匹配精确提示符 `"# "`。

### Task 4: 静态符号审计与可重定位零未决链接检查

**Files:**
- Create: `scripts/audit_lvgl_symbols.sh`

**Interfaces:**
- Consumes: `build/x86_64-clang/liblvgl/lib/liblvgl.a`, `build/x86_64-clang/staging/libc/usr/lib/libc.a`
- Produces: 自动化审计脚本，证明 `liblvgl.a` 合并后与 `libc.a` 链接后的未解析符号严格为 0。

- [ ] **Step 1: 编写 `scripts/audit_lvgl_symbols.sh`**
  ```bash
  #!/usr/bin/env bash
  set -euo pipefail

  ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
  BUILD_DIR="$ROOT/build/x86_64-clang"
  LVGL_OBJ_DIR="$BUILD_DIR/liblvgl/obj"
  LIBC_A="$BUILD_DIR/staging/libc/usr/lib/libc.a"
  OUT_DIR="$BUILD_DIR/audit"
  mkdir -p "$OUT_DIR"

  echo "[audit] Merging all liblvgl objects into $OUT_DIR/lvgl_combined.o..."
  OBJS=$(find "$LVGL_OBJ_DIR" -name '*.o')
  ld.lld -r $OBJS -o "$OUT_DIR/lvgl_combined.o"

  echo "[audit] Extracting undefined symbols from LVGL combined object..."
  llvm-nm --undefined-only "$OUT_DIR/lvgl_combined.o" | awk '{print $2}' | sort -u > "$OUT_DIR/lvgl_undef.txt"
  llvm-nm --defined-only "$LIBC_A" | awk '{print $3}' | sort -u > "$OUT_DIR/libc_def.txt"

  echo "[audit] Checking for forbidden math and pthread symbols..."
  FORBIDDEN=$(grep -E '^(cosf|sinf|tanf|roundf|powf|sqrtf|pthread_|sem_)' "$OUT_DIR/lvgl_undef.txt" || true)
  if [ -n "$FORBIDDEN" ]; then
    echo "ERROR: Forbidden symbols detected:"
    echo "$FORBIDDEN"
    exit 1
  fi

  echo "[audit] Checking set difference: all undefined symbols must be in libc_def..."
  DIFF=$(comm -23 "$OUT_DIR/lvgl_undef.txt" "$OUT_DIR/libc_def.txt")
  if [ -n "$DIFF" ]; then
    echo "ERROR: Undefined symbols not provided by libc.a:"
    echo "$DIFF"
    exit 1
  fi

  echo "[audit] Performing relocatable link with OS01 libc.a..."
  ld.lld -r "$OUT_DIR/lvgl_combined.o" "$LIBC_A" -o "$OUT_DIR/lvgl_libc_combined.o"

  REMAINING=$(llvm-nm --undefined-only "$OUT_DIR/lvgl_libc_combined.o")
  if [ -n "$REMAINING" ]; then
    echo "ERROR: Unresolved symbols remain after linking with libc.a:"
    echo "$REMAINING"
    exit 1
  fi

  echo "[audit] SUCCESS: Zero unresolved symbols remain. Symbol audit passed."
  ```
  赋予执行权限：`chmod +x scripts/audit_lvgl_symbols.sh`

- [ ] **Step 2: 运行符号审计脚本**
  运行：`scripts/audit_lvgl_symbols.sh`
  预期输出：`[audit] SUCCESS: Zero unresolved symbols remain. Symbol audit passed.`，返回码为 0。

- [ ] **Step 4: 编写并运行 `qemutests/test_lvgl_runner.py` 自动化测试脚本**
  编写支持 `selectors` 非阻塞分块累积、双阶段独立超时（启动就绪 25s + 测试执行 10s）、匹配严格 shell prompt `"# "`、使用 `printf '__SHELL_%s__\n' CANARY` 消除回显假阳性、并在发送后匹配独立结果行 `__SHELL_CANARY__`，最后注入测试命令并校验退出码的 Python 测试脚本：
  ```python
  #!/usr/bin/env python3
  import subprocess, sys, time, os, re, selectors
  from pathlib import Path

  ROOT = Path(__file__).resolve().parents[1]
  paths = subprocess.check_output(['make', '-s', 'PROFILE=x86_64-clang', 'print-run-paths'], text=True, cwd=ROOT)
  fw = re.search(r'^firmware=(.*)$', paths, re.M).group(1)
  img = re.search(r'^image=(.*)$', paths, re.M).group(1)

  log_path = ROOT / "build/x86_64-clang/test_lvgl_qemu.log"
  log_path.parent.mkdir(parents=True, exist_ok=True)
  log_file = open(log_path, "w", encoding="utf-8")

  cmd = [
      'qemu-system-x86_64', '-M', 'q35',
      '-drive', f'if=pflash,format=raw,readonly=on,file={fw}',
      '-drive', f'file={img},format=raw,if=none,id=disk',
      '-device', 'ahci,id=ahci',
      '-device', 'ide-hd,drive=disk,bus=ahci.0',
      '-m', '512', '-smp', '1',
      '-serial', 'stdio', '-display', 'none',
      '-no-reboot', '-no-shutdown'
  ]

  proc = subprocess.Popen(cmd, stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.STDOUT)
  sel = selectors.DefaultSelector()
  sel.register(proc.stdout, selectors.EVENT_READ)

  buffer = ""
  try:
      # 阶段 1：等待 Shell 就绪提示符 "# "（上限 25s）
      ready = False
      boot_deadline = time.monotonic() + 25.0
      while True:
          remaining = boot_deadline - time.monotonic()
          if remaining <= 0:
              break
          events = sel.select(timeout=min(remaining, 0.5))
          if events:
              chunk = os.read(proc.stdout.fileno(), 4096)
              if not chunk:
                  break
              text = chunk.decode('utf-8', errors='replace').replace('\r', '')
              buffer += text
              sys.stdout.write(text)
              sys.stdout.flush()
              log_file.write(text)
              log_file.flush()
              if buffer.endswith("# ") or "\n# " in buffer:
                  ready = True
                  break

      if not ready:
          print("\nERROR: Boot timeout (25s) before seeing '# ' shell prompt", file=sys.stderr)
          sys.exit(1)

      # 握手验证：在启动阶段剩余预算内，发送拼接命令以消除终端回显误判
      proc.stdin.write(b"printf '__SHELL_%s__\\n' CANARY\n")
      proc.stdin.flush()
      
      handshake_ok = False
      handshake_buf = ""
      while time.monotonic() < boot_deadline:
          remaining = boot_deadline - time.monotonic()
          events = sel.select(timeout=min(remaining, 0.2))
          if events:
              chunk = os.read(proc.stdout.fileno(), 4096)
              if not chunk:
                  break
              text = chunk.decode('utf-8', errors='replace').replace('\r', '')
              handshake_buf += text
              sys.stdout.write(text)
              log_file.write(text)
              # 严格断言在命令发送后出现独立整行 __SHELL_CANARY__
              if re.search(r'(^|\n)__SHELL_CANARY__(\n|$)', handshake_buf):
                  handshake_ok = True
                  break
      if not handshake_ok:
          print("\nERROR: Shell failed to execute canary handshake within boot deadline", file=sys.stderr)
          sys.exit(1)

      # 阶段 2：注入测试命令并等待测试执行结果（独立上限 10s）
      proc.stdin.write(b'/bin/test_lvgl\necho LVGL_EXIT_CODE:$?\n')
      proc.stdin.flush()

      test_pass = False
      exit_code_zero = False
      exec_buf = ""
      exec_deadline = time.monotonic() + 10.0

      while True:
          remaining = exec_deadline - time.monotonic()
          if remaining <= 0:
              break
          events = sel.select(timeout=min(remaining, 0.5))
          if events:
              chunk = os.read(proc.stdout.fileno(), 4096)
              if not chunk:
                  break
              text = chunk.decode('utf-8', errors='replace').replace('\r', '')
              exec_buf += text
              sys.stdout.write(text)
              sys.stdout.flush()
              log_file.write(text)
              log_file.flush()
              if "[TEST PASS] LVGL compatibility smoke test succeeded." in exec_buf:
                  test_pass = True
              if re.search(r'(^|\n)LVGL_EXIT_CODE:0(\n|$)', exec_buf):
                  exit_code_zero = True
              if test_pass and exit_code_zero:
                  break

      if not test_pass:
          print("\nERROR: [TEST PASS] message not found within execution deadline", file=sys.stderr)
          sys.exit(1)
      if not exit_code_zero:
          print("\nERROR: LVGL_EXIT_CODE:0 not found within execution deadline", file=sys.stderr)
          sys.exit(1)

      print("\nQEMU headless test verified successfully.")

  finally:
      log_file.close()
      if proc.poll() is None:
          proc.terminate()
          try:
              proc.wait(timeout=2)
          except subprocess.TimeoutExpired:
              proc.kill()
              proc.wait()
  ```
