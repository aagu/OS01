# libc 最小真实 libm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Follow the tasks in order and use the checkboxes to record verified results.

**目标**　以 musl 1.2.5 为基线，把 16 个用户态数学函数编进独立的 `libm.a`，由 sysroot 发布。更新公开头与既有调用方，并用宿主 oracle、guest systest 和归档审计验收。

**设计依据**　[libm spec v5](../specs/2026-11-21-libm-design.md)。以下均为待执行步骤。任务顺序为 T1 归档、T2 公开接口及归档归属、T3 宿主数值契约、T4 guest、T5 指令审计与交付。

## 共同约定

- 公开符号为 `fabs/fabsf/copysign/copysignf/floor/floorf/ceil/ceilf/trunc/truncf/round/roundf/fmod/fmodf/sqrt/sqrtf`。用户态 `libm.a` 单独构建。两个 profile 的 `libc.a`、`libk.a` 均不得定义这些符号。
- 数值核心使用整数位操作。平方根固定采用最近值舍入。按 spec 的顺序先判断 NaN，再判断域错误。错误路径设置 `EDOM`，其余路径保留 `errno`。固定 quiet NaN 分别为 binary64 `0x7ff8000000000000`、binary32 `0x7fc00000`。取整函数保留 NaN 原位模式，`fabs` 和 `copysign` 家族按规则改变符号并保留载荷。
- 从仓库根执行 Make。任何日志管道都用 Bash 的 `set -o pipefail` 保留退出状态。增量迁移与负向验证使用当前任务的隔离工作树或独立临时输入，保留原有工作区和构建结果。
- 新宿主测试使用 `@os01-test` 元数据，运行 `make regen-test-catalog` 并纳入实际变更的生成文件。每项任务通过验证后提交其列出的文件，提交前检查实际 diff。
- 数值探针、oracle 和 guest 用例均使用运行时参数或带可观测外部引用的函数调用。用对象符号或链接映射确认测到了目标实现。

## T1　构建并发布真实归档

**文件**　新增 `libc/math/` 下的 16 个函数实现、`sqrt_data.c`、`sqrt_data.h`、`musl_libm.h`。修改 `libc/Makefile`、`mk/components/sysroot.mk`、`thirdpart/musl-libc-algorithms.manifest`。

**接口**　任务产出 `$(LIBC_BUILD_DIR)/lib/libm.a` 和 `$(SYSROOT)/usr/lib/libm.a`。归档内另有 `sqrt_data.o` 定义的全局内部表 `__os01_libm_rsqrt_tab`。

- [ ] **记录迁移基线。** 在隔离工作树的未修改版本从根运行 `make PROFILE=x86_64-clang lib`。保留 staging 和 receipts，确认 `build/x86_64-clang/staging/compat-libs/usr/lib/libm.a` 存在，其 manifest 列出该路径，安装归档缺少公开符号。记录可验证的缺失诊断。
- [ ] **取源并校验。** 用 `mktemp -d` 建工作目录，从 `https://musl.libc.org/releases/musl-1.2.5.tar.gz` 下载归档。用 `sha256sum -c` 校验 `a9a118bbe84d8764da0ea0d28b3ab3fae8477fc7e4085d90102b8596fc7c75e4`，校验成功后解包。以归档中的 `src/math/` 作为每个实现与查表数据的来源，保留许可证与上游注明的版权。
- [ ] **移植实现。** 把上游私有依赖集中到源目录中的 `musl_libm.h`。它提供位转换和分支提示，`sqrt_data.h` 声明改名后的表。用下表核对逐文件适配，manifest 记录上游路径、校验值和 spec 的 13 条适配。

| 文件 | 适配与必须保留的性质 |
|---|---|
| `fabs{,f}.c`、`copysign{,f}.c` | 保留上游位操作，用私有头取代不再需要的公开头及内部头依赖。只触碰符号位。 |
| `trunc{,f}.c`、`floorf.c`、`ceilf.c` | 删除各文件实际存在的全部 `FORCE_EVAL` 异常触发，保留符号零、次正规数和 NaN 行为。 |
| `floor.c`、`ceil.c`、`round{,f}.c` | 按指数确定整数截断位置。绝对值小于 1 的输入单独处理。其余输入按位掩去小数部分，再按方向或半远离零条件加一个整数单位。加法前先清尾数中的小数位。已是整数、无穷与 NaN 原样返回。 |
| `fmod{,f}.c` | 保留上游整数长除。对两个入参按各自宽度先做 NaN 位检测。随后处理无穷被除数和零除数的 `EDOM`，再处理无穷除数。精确余数为零时从被除数符号位直接构造零。 |
| `sqrt{,f}.c` | 保留上游定点迭代和最终舍入。按 spec 次序判断 NaN、负数、有符号零和正无穷。禁用 FENV 收尾。用 spec 的整数公式重建浮点缩放位模式，最高置位只对非零尾数求值，先按输出宽度转为无符号整数再左移。binary64 对 `top` 减 52，binary32 执行 `ix -= 23U << 23`。 |
| `sqrt_data.c`、`sqrt_data.h` | 从校验后的上游文件复制原表和声明，移除 musl 私有可见性依赖并统一改名。表项顺序和位模式保持原样。 |

- [ ] **接入构建。** 在 `libc/Makefile` 中定义 `LIBM_OBJS` 与 `LIBM_ARCHIVE`，给归档目标添加实际配方，通过 `TARGET_AR` 从该对象列表建档。现有对象编译规则生成 `math/*.o` 和 `.d`，把后者加入 `ALL_DEPS`。把归档加入 `all` 和 `install-libs` 的前置依赖并安装到 `usr/lib/libm.a`。同时处理源文件列表改变后的归档成员重建，避免旧成员滞留。compat-libs 改为只生成 `librt.a` 并在扫描 manifest 前移除 staging 中的旧 `libm.a`。
- [ ] **验证增量与干净构建。** 在有迁移基线的构建树运行 `make PROFILE=x86_64-clang lib`。确认 staging 只保留 `librt.a`，compat manifest 没有 `usr/lib/libm.a`，新 generation 成功发布。再在干净构建树分别执行下列命令。两份安装归档各包含准确的 16 个公开函数和内部表。用 `llvm-nm -g --defined-only` 比较符号集合，检查本地归档与发布归档字节相同。

```sh
make PROFILE=x86_64-clang lib
make PROFILE=aarch64-clang lib
```

- [ ] **验证私有头依赖。** 临时给私有头增加等价的注释并重建，检查依赖它的目标对象确实重新编译且归档得到更新。复原探针改动后再重建。生成号仅在发布内容变化时要求更新。
- [ ] **提交 T1 列出的文件。**

## T2　公开头、调用方和 API 归档归属

**文件**　修改 `libc/include/math.h`、`libc/include/libc_arch/{x86_64,aarch64}/float_abi.h`、`user/doom/app.mk`、`hosttests/cases/test_libc_float_parse.c`、`hosttests/mk/libc.mk`、`scripts/audit_libc_api.py`、`mk/components/run.mk`。新增 `hosttests/cases/test_libc_math.c` 及其 C++ 探针 `hosttests/mock/libm_cxx_probe.cpp`，纳入本任务产生的测试目录变更。

**接口**　宿主对象来自 T1 实现，定义全部 `os01_*` 数学符号，错误状态用普通全局 `os01_errno`。T3 复用 `LINK_GROUP_libc-math` 和 `test_libc_math`。

- [ ] **编写并接通头契约测试。** 用元数据 `id: test_libc_math`、`layer: host`、`subsystem: libc`、`timing: strict`、`tier: nightly`、`link: libc-math`、`scenarios: []` 注册 C 测试。用现有 `TEST_FUNC`、`TEST_LIST_BEGIN/TEST_LIST_END` 和 `main` 组织断言，`main` 在断言失败时返回非零。接入 C++17 freestanding 探针、宿主编译对象与根测试入口后先运行测试，确认旧头因缺少分类宏或声明而失败。编译探针和 OS01 调用侧都包含仓库头，C++ 探针通过 `-Dfabs=os01_fabs -fno-builtin` 引用仓库实现。检查未定义引用是 `os01_fabs` 而且链接实际解析到改名对象。宿主对象用 `HOST_CFLAGS`、`LIBC_INC`、`-MMD -MP` 编译，逐一改名 16 个函数并传 `-Derrno=os01_errno`。链接组包括全部这些对象及 C++ 探针。测试 TU 提供 `int os01_errno`。
- [ ] **实现公开头与探针约定。** 16 个声明放入 C linkage 区块。`INFINITY` 与 `NAN` 使用 `float.h` 的同一替换列表。声明 spec 的常量和分类宏。`MATH_ERRNO=1`、`MATH_ERREXCEPT=2`，`math_errhandling` 仅设置前者。
  - C 用 `_Generic` 做类型分派，C++ 在 C linkage 区块外用内部重载和整数兜底。只对整数兜底转换为 `double`，实参只求值一次。对 `float` 与 `double` 用对应类型的 builtin。
  - `long double` 用对象表示的整数读取，避免浮点缩窄及软浮点比较。x87 读取符号、15 位指数和 64 位有效数字。指数全 1 且有效数字恰为 `0x8000000000000000` 时为无穷，其他指数全 1 的编码为 NaN。canonical 正规数和次正规数按指数与有效数字区分。binary128 指数全 1 时检查完整 112 位尾数。`signbit` 读取原始符号。用无别名问题的字节复制读取表示，跳过 x87 填充。
  - 断言两种语言的 `isnormal(5)` 为真、`isnormal(0)` 为假，负零符号正确，最小正 float 为次正规，`LDBL_MAX` 有限，正负 long double 无穷与 NaN 分类正确，带副作用的实参执行一次。用两个 profile 的目标编译器构建 C 与 C++ 探针，aarch64 的 binary128 探针不得引用浮点转换或比较软浮点符号。
- [ ] **迁移既有调用者。** 两种扫描器各自通过整数位操作清除工作类型符号。`test_libc_float_parse` 的两个 TU 保留 `fabs` 改名，相关 ELF 增加 `$(TEST_BLD)/user-libm/fabs.o` 依赖。更新其 Layer 4 注释并保留所有现有断言。核对两 TU 的 depfile 都跟踪 `math.h`，扫描器对象跟踪对应的 `float_abi.h`。Doom 的 `APP_LDLIBS` 在 `-lgui -lgfx` 后加 `-lm`。
- [ ] **同一任务接入 API 清单和归档检查。** 在 `scripts/audit_libc_api.py` 共用一份 16 名函数清单，同时供 `math.h` 声明检查与 libm 归属检查使用。避免把这些函数算作 `libc.a` 的必需导出。新增 `--libm-archive`，保留仅检查头文件、C 清单生成、现有 libc/libk 分组及用户态与内核能力分支。只对 libm 的符号应用跨归档排他检查。现有 libc 与 libk 允许共同定义的符号继续通过。让用户态的 `test-libc-api-audit` 在 `lib` 发布之后显式传入 `$(SYSROOT)/usr/lib/libm.a`。缺归档、缺公开符号或任一公开数学符号落入 libc/libk 都应返回非零。用临时空归档和混入 `fabs` 的临时归档分别验证拒绝路径。
- [ ] **运行回归。** 用实际根入口重跑 RED 对应的测试并检查通过，检查两个 profile 的归属审计。Doom ELF 必须在对应变体中实际定义 `fabs`，用链接映射或 `v_video.o` 的引用结合归档成员证明来源。BusyBox 必须成功链接，检查其真实链接命令搜索已发布的 sysroot 库目录。

## T3　宿主 glibc 对照与特殊值契约

**文件**　新增 `hosttests/data/libm_cases.h`、`hosttests/oracle/libm_oracle.c`。修改 `hosttests/cases/test_libc_math.c`、`hosttests/mk/libc.mk`。

- [ ] **先扩展用例与入口。** 用例包含唯一 ID、操作、位宽、两个输入位模式、比较策略和显式期望 `errno`。每种有意义的路径同时覆盖 float 与 double。覆盖以下表中的输入，常规值使用 glibc 参考位模式，特殊路径保留独立期望。

| 函数组 | 必须覆盖的输入与结果 |
|---|---|
| `fabs`、`copysign` | 符号零、负值、无穷、有非零载荷的正负 quiet/signaling NaN。按掩码断言符号与载荷。 |
| `floor`、`ceil`、`trunc`、`round` | 正负零、零附近次正规数、±0.5 和其两侧的邻接值、±1.5、±2.5、有效数字整数边界、大整数、无穷、NaN 原样返回。 |
| `fmod` | 普通取余、精确整除产生负零、次正规余数、有限数对无穷取余。域错误分别覆盖零除数、正负无穷被除数及 `fmod(inf, inf)`。NaN 优先覆盖 `fmod(NaN, 0)`、`fmod(inf, NaN)` 和负 NaN，返回固定 quiet NaN 且保留哨兵。 |
| `sqrt` | 普通正数、负数、负无穷、正无穷、有符号零、正负 quiet/signaling NaN。按位构造最小、次小、最大次正规数及 binary64 `m=2^51`、binary32 `m=2^22` 边界。 |

- [ ] **构建独立 oracle。** 使用宿主标准头与 `-fno-builtin`，配方把 `-lm` 放在源文件之后。将 oracle 加入 `LIBC_HOST_ORACLES`，用 `LINK_CFLAGS_libc-math` 保留 `HOST_CFLAGS` 并传 `LIBM_ORACLE_PATH`。共享表同时是 oracle 与测试对象的依赖。在 `hosttests/mk/libc.mk` 为现有生成 ELF 目标补一条无配方的依赖，保持生成器及元数据格式。

```make
$(TEST_BLD)/test_libc_math.elf: | $(TEST_BLD)/libm_oracle
```

- [ ] **逐字段验证。** 复用现有宿主 oracle 进程模式。每次 glibc 调用前把宿主 `errno` 置为约定哨兵，调用后立即保存。输出 ID、位宽、返回位模式与 `errno`。父进程验证子进程正常退出且状态为 0，逐条验证格式、位宽和已知 ID，拒绝额外、重复、缺行或截断。测试中的 `os01_errno` 每次独立设为同一哨兵。根据用例策略对照 oracle 或本项目规定的位模式。每行的 OS01 错误状态均对照用例的显式期望 `errno`。oracle 的 `errno` 用于诊断，OS01 的 NaN 与错误契约由用例独立判定。
- [ ] **验证捕错能力。** 用隔离的 oracle 输出注入重复 ID、错误位宽及非零退出状态，确认测试失败。使用原 oracle 重跑 `make PROFILE=x86_64-clang test-host`，确认 `test_libc_math` 通过。在干净构建验证单独请求生成的 ELF 时也生成 oracle。宿主 libm 私有头的变更必须通过 depfile 触发重编译。

- [ ] **实现整数位模式断言。** 用独立的硬编码向量覆盖 16 个函数。下表是每个符号的最少普通输入。位模式使用 `memcpy` 等位复制取得，浮点比较不充当验收依据。

| 双精度 / 单精度函数 | 输入 | binary64 期望 | binary32 期望 |
|---|---|---|---|
| `fabs/fabsf` | −0 | `0000000000000000` | `00000000` |

## T5　指令审计、文档与交付

**文件**　新增 `scripts/audit_libm_asm.py`，修改 `mk/components/run.mk`、`docs/roadmap.md`、`docs/build/build.md`。若实现较初次移植有差异，同步修改 `thirdpart/musl-libc-algorithms.manifest`。

- [ ] **实现反汇编审计。** 提供 `python3 scripts/audit_libm_asm.py --archive PATH --profile PROFILE --objdump TOOL`。审计安装归档，用 `llvm-objdump -d --no-show-raw-insn` 并按其无原始字节输出解析每条地址之后的助记符。成功条件包括所有 16 个公开函数体均识别且每个至少有一条指令，数据成员不要求指令。拒绝错误架构、反汇编失败、缺失函数或无法解析指令。对 x86_64 的 x87、SSE/AVX 同族和 aarch64 scalar/vector 指令都覆盖浮点加减乘除、FMA、平方根、比较、取整与转换。排除误伤整数算术和 ABI 搬运。对 aarch64 的等价符号位指令按 spec 检查带载荷 NaN 与符号零的位语义。
