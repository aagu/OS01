# D02 — 纯 PS/2 解码器公开接口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 公开既有 PS/2 解码器并验证 sysroot 安装及无 LVGL 静态抽取边界。

**Architecture:** 移动公共声明，不复制状态机。保留兼容转发头；从 immutable sysroot 编译独立消费者。

**Tech Stack:** freestanding C、Clang/LLVM、GNU Make、现有 hosttests/Python harness。

**Spec:** [纯 PS/2 解码器公开接口](../specs/2026-11-10-doom-02-ps2-api-design.md)。状态：文档评审通过，全部步骤未执行。

**前置：** 无 D01/D03 依赖；沿用当前 libgui 构建。

## Global Constraints

- 遵守[总览公共约束](../specs/2026-11-10-doom-port-design.md)；仅根 make、profile 私有产物，不覆盖已有工作区修改。
- 签名、gui_ps2_state_t 布局和 100 ms 超时语义不变。
- 只公开既有能力，不改 gui_input_create 或引入新的设备管理层。
- 应用探针不得添加 libgui/internal include 路径。

## Review Focus

- E0 前缀跨 read 的 DOWN/UP 仍配对 → T1。
- 重复 make/Caps 与双修饰键行为不变 → T1。
- 仅安装头路径即可独立编译 → T2。
- 只用 gui_ps2_* 不拉入 LVGL/platform 对象 → T2。
- 只修改公开头也会刷新 generation/消费者 → T2。
