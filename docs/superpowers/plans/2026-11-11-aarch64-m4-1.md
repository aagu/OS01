# AArch64 M4.1 Implementation Plan

> Execute inline using superpowers:executing-plans.

**Goal:** Demonstrate isolated AArch64 user address spaces and the first real EL0 round trip.

**Architecture:** Use M3 to populate private TTBR0 roots. A BSP-only, pre-SMP selftest enters EL0, dispatches synchronous exceptions through a saved register frame, and returns to its EL1 caller. Reuse the existing selftest image and serial result.

**Scope:** The agreed M4.1 slice: single CPU, fixed mappings, embedded test code, SVC and permission faults, teardown. VFS, ELF, VMA, uaccess, fork/COW, and production user tasks are follow-ups.

- [x] Register the acceptance test and observe failure with no EL0 backend.
- [x] Implement private page table creation, mapping and teardown, and an EL0 entry with a local TLB flush on both root changes.
- [x] Exercise two roots at the same VA, SVC return, permission faults and repeated reclaim. Confirm ordinary builds retain disabled userspace.
- [x] Run one QEMU boot for M4.1 and the existing M3 and positive scheduler regressions. Document the short verification command.

Verification: single-core EL0 selftest passed (15/15 overall); M3 probe and all eight positive scheduler boots passed. A conflicting sync-fault selector is rejected at make parse time.
