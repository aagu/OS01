# AArch64 M4.6 Implementation Plan

**Goal:** Use real EL0 timer IRQs to switch between two private user contexts.

**Architecture:** Extend the M4 pair runner with an optional timer-return callback. The lower-EL IRQ adapter invokes it only after CNTP dispatch and GIC EOI. Reuse the parked frame and TTBR0 swap. Limit the IRQ pair to the single BSP before scheduler handoff.

- [x] Extend the fixture and late selftest to require three timer-driven handoffs. SVCs only report progress or completion, and bound the wait. Observe failure with the single-context IRQ runner.
- [x] Add the timer-return callback and enable IRQs for both private contexts. Require A → B → A → B via CNTP, verify both resumed contexts, and reclaim both roots.
- [x] Run the existing single-core QEMU selftest and confirm the ordinary image excludes the probe.

Verification: the single-context IRQ runner timed out with zero switches (17/18). The IRQ pair runner passed the same QEMU boot (18/18). The normal UEFI image built without the probe symbols.
