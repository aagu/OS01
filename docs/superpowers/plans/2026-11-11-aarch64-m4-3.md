# AArch64 M4.3 Implementation Plan

**Goal:** Run a linked AArch64 ELF in the existing EL0 probe.

**Architecture:** Build a freestanding ET_EXEC fixture with separate RX and RW segments. Reuse the shared ELF layout validator with an explicit machine, then load the validated bytes into a fresh private root and start at e_entry. Keep the fixture and loader gated to the M4 probe image.

- [x] Link and embed the fixture; observe the probe fail without the loader.
- [x] Load bounded static PT_LOAD segments, zero BSS, apply permissions and clean executable bytes for EL0. Reject invalid input before allocating and unwind partial loads.
- [x] Reuse the single QEMU case to verify the entry, data/BSS, M4.1/M4.2 behavior, bad entry and PMM baseline. Check the existing host ELF validator test.

Verification: the linked fixture has entry 0x400010 and two PT_LOAD segments (RX and RW). The single-core suite passed 15/15; the existing host ELF layout test passed all 30 cases, including truncated program-header table rejection.
