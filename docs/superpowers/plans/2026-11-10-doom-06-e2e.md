# D06 — Doom QEMU 集成验收 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立真实Doom的SMP=1/2 QEMU闭环验收并保存可复核证据。

**Architecture:** 复用现有QMP/截图harness，正常terminal/ash启动游戏；独立test镜像variant加每场景可写副本，避免污染普通镜像。

**Tech Stack:** freestanding C、Clang/LLVM、GNU Make、现有 hosttests/Python harness、QEMU/QMP。

**Spec:** [Doom QEMU 集成验收](../specs/2026-11-10-doom-06-e2e-design.md)。状态：文档评审通过，全部步骤未执行。

**前置：** D01–D05已完成；本地可用真实IWAD及其四项校验/来源输入已提供。

## Global Constraints

- 遵守[总览公共约束](../specs/2026-11-10-doom-port-design.md)；仅根 make、profile 私有产物，不覆盖已有工作区修改。
- rootfs、SMP=1/2、512MiB、isolated；真实键盘由QMP make/break注入。
- DOOM_TEST=1隔离镜像与诊断构建身份，正常inittab；不以init替换规避terminal归还。
- 显式SUITE=doom缺资源硬失败；不自动加时；fake runner测试不证明游戏运行。

## Review Focus

- 缺WAD、只有echo的伪握手不得绿色通过 → T1。
- runner超时/崩溃清理且保留日志截图 → T1。
- 两CPU和场景副本互不污染普通image → T2。
- SIGKILL控制路径不能依赖游戏占有的TTY键盘 → T3。
- 配置Ctrl/Space往返及跨VM存档需要真实状态证据 → T3。
